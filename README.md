# 小米音乐 自动赚时长（AScript）

基于 [AScript](https://www.ascript.cn) 安卓引擎的自动化脚本：自动点「免」、看互动广告、领奖励，
给小米音乐（`com.miui.player`）刷「免费听」时长。

- 平台：Android，AScript 4.0.17+（无障碍模式）
- 实测设备：1440×3200 / Android（vivo V2055A 同级别）
- OCR：paddle（百度 PP-OCR V5）

## 功能流程

入口是**发现页右上角的「免」徽标**，它有两种形态：

| 状态 | 徽标样式 | 点下去 |
|---|---|---|
| 无时长 | 单颗灰边圆徽标 `(1320, 232)` | 直接进广告 |
| 有时长 | 绿色圆环「免」+ `15:21` 胶囊 `(1194, 233)` | 跳到「免费听」页 |

```
启动 App → 跳开屏广告 → 清弹窗（含豪华绿钻续费弹窗）
    ↓
第 1 轮：切「发现」→ 点「免」→（落到广告页或免费听页）
    ↓
免费听页 → 点「加时长」（失败→任务卡「观看」）→ 广告页
    ↓
点「点击浏览10秒」→（可能弹「是否允许启动淘宝」→ 点允许）→ 跳淘宝
    ↓
等 12s → 拉起小米音乐 → 左上角「🎁 恭喜已获得奖励」→ 点右上角 ✕
    ↓
App 自动回到「免费听」页 → 读顶部倒计时 00:15:35
    ↓
第 2 轮起：不绕发现页，直接点「加时长」→ 循环
    ↓
比上一轮多 → 成功 +1；连续 6 轮没收益 → 当日额度用完，退出
```

## 快速开始

1. 手机装 AScript App，开**无障碍**权限；「开发者」页开**设备服务**（端口 9096）
2. `.vscode/settings.json` 里填手机 IP（当前 `192.168.0.158:9096`，换网络要改）
3. VS Code 装 AScript 插件 → 命令面板 `AScript: 扫描设备` 添加设备 → `AScript: 选择运行设备`
4. `AScript: 在设备上运行当前工程`

> ⚠️ 插件的设备列表存在 `globalState`，**不是** `settings.json`。`ascript.deviceId` 只是引用，
> 设备列表为空时报「未找到 Android 设备」，必须先扫描/手动添加一次。

脱机运行：AScript「工程管理」→ 运行；或「打包独立程序」生成 APK。

## 配置

`__init__.py` 头部：

| 常量 | 默认 | 说明 |
|------|------|------|
| `APP_PACKAGE` | `com.miui.player` | 包名 |
| `MAX_LOOP_COUNT` | `20` | 最大轮数（约 10~12 分钟） |
| `MAX_IDLE_ROUNDS` | `6` | 连续多少轮没收益退出 |
| `LOOP_INTERVAL` | `2.5` | 每轮间隔 |
| `AD_TIMEOUT` | `80` | 单轮广告最长等待 |
| `BROWSE_SECONDS` | `12` | 点进第三方后停留（广告要求 10s） |
| `SKIP_AFTER_SEC` | `12` | 有「跳过」时至少等多久再点 |
| `AUTO_BROWSE_AD` | `True` | 自动点「点击浏览N秒」 |
| `KEEP_SCREEN_ON` | `True` | 屏幕常亮 |
| `AUTO_RESTART_APP` | `True` | 连续卡住自动重开 |
| `OCR_ENGINE` | `"paddle"` | 可换 `"mlkit"`（更快） |
| `SELF_TEST` | `False` | 体检模式：只识别不点广告 |
| `SELF_TEST_ENTER_AD` | `False` | 体检时点一次「免」看落地 |
| `MIAN_X_RATIO` / `MIAN_Y_RATIO` | `0.9167` / `0.0725` | 无时长时「免」坐标 |
| `NAV_DISCOVER_RATIO` | `(0.0986, 0.958)` | 底部「发现」兜底 |
| `AD_CLOSE_RATIO` | `(0.9329, 0.0839)` | 广告页右上角 ✕ |
| `VERIFY_BY_FREE_TIME` | `True` | 广告后在免费听页读倒计时核对 |

## 踩过的坑

### ① 「免」的位置会变

有时长时右侧多出 `15:21`，胶囊右边缘不动，**圆心被挤到左边 126px**。
脚本不是死点坐标：`find_mian_xy()` 先读旁边的时长文字，再按 `x = time_cx - W×(0.038+0.006×字符数)` 反推圆心；
读不到才退回固定坐标。

### ② 互动广告必须点进第三方

广告页底部白卡有「点击浏览10秒」，**光等不发奖**，必须点进去浏览满 10 秒。
点击范围限定在 y 70%~98%（底部白卡），避免误点顶部那句「点击广告浏览10秒可获得奖励」。

### ③ 会弹「是否允许启动淘宝」

不点允许就跳不过去。`allow_app_jump()` 的处理：

- **只在屏幕出现「允许」时才动作** —— 否则会把免费听页任务卡的「打开"元宝"聊天并浏览1秒」当按钮
- 优先 `允许本次启动` → `仅此一次` → `始终允许` → `允许`
- **排除 `不允许/禁止/拒绝`**（`"允许" in "不允许"` 会误点，必须显式排除）

### ④ 淘宝详情页吞返回键

实测连按 3 次返回都还在 `com.taobao.taobao`。
所以 `return_to_app()` 是**直接 `system.open(APP_PACKAGE)` 拉起**，返回键只兜底。

### ⑤ 豪华绿钻续费弹窗，绝不能点

播放页会弹「已过期 851 天」+ 绿色按钮「¥1.88立即续费豪华绿钻」，点错真扣钱。
全局 `DANGER_WORDS`（续费/开通/支付/购买/充值/下载/安装/¥/￥/会员/详情页）+ `is_danger()`，
所有点击前置过滤，任何路径都点不到它。

### ⑥ 免费听页任务卡有「点击浏览1秒」

这个坑词会命中广告页特征 `"点击浏览"`，把免费听页误判成广告页。
所以 `AD_HINTS` 不含这个泛词，且 `wait_entry_result()` **先认免费听页，再认广告页**。

### ⑦ 启动后前台可能还是桌面

`system.open()` 后 3 秒 `get_foreground_app()` 可能仍报 `com.miui.home`。
`wait_app()` 用 `wait_for_package` + 前台包名轮询，最多等 12 秒。

## 成功判定

不靠文案猜，**读数字**：

```
点广告前：00:15:35 → 935 秒
跑完一轮：00:35:35 → 2135 秒
差值 > 0 → 真成功
```

读不到倒计时（OCR 失败）时才退化为「有奖励提示即成功」，日志会标明。

## 已知限制

1. 比例坐标按 1440×3200 实测，换分辨率要重测（改 `r_*()` 与 `*_RATIO`）
2. `Ocr.find_all()` 单次约 0.8s（paddle），每轮至少一次全屏 OCR
3. 不点「去浏览」类限时任务（会拉起「元宝」App，与广告无关）
4. 只适配竖屏
5. 每日额度由服务端控制，跑完 `加时长` 变灰后脚本会自动退出
